## 6. Máximo con empates

```python
ventas = [85, 120, 90, 120, 75]
maximo = max(ventas)
posiciones = []

for posicion, venta in enumerate(ventas):
    if venta == maximo:
        posiciones.append(posicion)

print(maximo, posiciones)
```

```

## 9. Sin repetidos

for dato in datos:

        unicos.append(dato)

print(unicos)
```

## 10. Comprensión explicada

```python
dobles = []

for numero in range(1, 10):
    if numero % 2 != 0:
        dobles.append(numero * 2)

dobles_comprension = [numero * 2 for numero in range(1, 10) if numero % 2 != 0]
print(dobles, dobles_comprension)
```

La comprensión recorre los enteros del 1 al 9, selecciona los impares y guarda el doble de cada uno.

## 12. Condición booleana

```python
def puede_registrar(cupos, inscritos):
    return inscritos < cupos


cupos = 4
inscritos = 0

while puede_registrar(cupos, inscritos):
    inscritos = inscritos + 1
    print("Registro", inscritos)
```
