## Ejercicio 1 — Predicción de salida

Sin ejecutar, escribe la salida exacta:

```python
print("Inicio")
print("Observar")
print("Describir")
print("Fin")
```

Luego ejecútalo y compara.

## Ejercicio 2 — Orden incorrecto

El siguiente programa intenta describir un procedimiento, pero sus pasos están desordenados:

```python
print("3. Presentar el resultado")
print("1. Comprender el problema")
print("2. Describir los pasos")
```

Reordena las instrucciones sin cambiar los mensajes.

## Ejercicio 6 — Mismo programa, dos entornos

Crea el archivo `u01_presentacion.py` con:

```python

print("Fundamentos de Programación")
print("Problema elegido: describir aquí")
print("Resultado esperado: describir aquí")
```

1. Ejecuta el archivo completo en Spyder.
2. Copia el código a una celda de Colab y ejecútala.
3. Describe dónde apareció la salida en cada entorno.
4. Cambia un mensaje y vuelve a ejecutar.

## Ejercicio 7 — Comentarios útiles

Mejora los comentarios:

```python

print("Reporte de observación")

# Imprime línea 2
print("Estado: listo para revisión")
```

Los nuevos comentarios deben explicar la intención, no repetir la instrucción.

## Entrega sugerida

- Un archivo `.py` ejecutable.
- Una captura o registro de la salida en uno de los entornos.
- La tabla entrada–proceso–salida del problema elegido.
- Una explicación breve de cualquier error corregido.

## Criterios de revisión

| Criterio | Evidencia esperada |
|---|---|
| Comprensión del problema | Necesidad concreta y persona usuaria identificada |
| Descomposición | Entrada, proceso y salida coherentes |
| Código | Instrucciones válidas y ordenadas |
| Lectura | Predicción de salida correcta |
| Diagnóstico | Explicación concreta de los errores |
| Entorno | Ejecución comprobada en Spyder o Colab |
