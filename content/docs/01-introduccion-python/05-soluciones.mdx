## Solución 3 — Corrige los errores

```python
print("Fundamentos de Programación")
print("Unidad 01")
print("Entorno preparado")
```

Correcciones:

- `Print` cambió a `print`: esto no es un error de sintaxis (el código original sí es válido), sino que produciría `NameError` al ejecutarlo, porque Python distingue mayúsculas y minúsculas y no existe ninguna función llamada `Print`.
- Se agregó la comilla de cierre en `"Unidad 01"` — esto sí es un error de sintaxis (comilla sin cerrar).
- Se agregaron comillas alrededor de `"Entorno preparado"` porque es texto literal — este también es un error de sintaxis.

## Solución 5 — Aplicación profesional

Ejemplo para gestión ambiental:

- **Necesidad:** presentar el estado de un punto de muestreo.
- **Entradas:** identificación del punto, lugar y observación registrada.
- **Proceso:** organizar la información para revisión.
- **Salida:** ficha resumida del punto.
- **Verificación:** comparar la ficha con el registro de campo.

Prototipo:

```python
# Encabezado que identifica el propósito del reporte
print("Ficha de punto de muestreo")

# Campos que deberá completar una versión posterior
print("Identificación: pendiente")
print("Lugar: pendiente")
print("Estado: listo para revisión")
```

## Solución 6 — Mismo programa, dos entornos

El contenido del programa es igual en ambos entornos. La diferencia observable es:

- Spyder muestra la salida en la consola de IPython al ejecutar el archivo.
- Colab muestra la salida debajo de la celda ejecutada.

Después de modificar un mensaje, es necesario guardar y ejecutar nuevamente en Spyder o volver a ejecutar la celda en Colab.
