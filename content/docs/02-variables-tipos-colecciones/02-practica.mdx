## Ejercicios

1. Crea variables para nombre, edad, estatura y estado de matrícula. Muestra cada valor y su tipo.
2. Convierte `"125"` a entero y `"19.75"` a flotante. Muestra la suma.
3. Limpia `"  ESPOL - Guayaquil  "`, conviértelo a minúsculas y reemplaza `espol` por `ESPOL`.
4. Dada `codigos = ["A", "B", "A", "C", "A"]`, informa si aparece `"A"`, su primera posición y cuántas veces se repite.
5. Crea una lista de cinco temas. Agrega uno, elimina uno y muestra el primero, el último y el tamaño.
6. Simula un dado con `randint`; elige un tema con `choice`; selecciona tres estudiantes con reemplazo usando `choices` y tres sin reemplazo usando `sample`.
7. Mezcla una lista de turnos con `shuffle`. Comprueba que la operación modifica la lista original *in place*; el orden podría coincidir por azar con el inicial.
8. Presenta un producto y su precio con dos decimales usando una f-string y luego `str.format()`.

No uses listas anidadas ni estructuras de control.
